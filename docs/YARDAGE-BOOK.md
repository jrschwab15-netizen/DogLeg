# Yardage Book and focused Home

Home now prioritizes Log a round / Resume your round, with the original photograph, a compact latest-round row and one Yardage Book link. Dashboard grids have moved out of Home. Mobile navigation is Home, Rounds, Add, Yardage Book, Profile. Courses and Friends remain available in desktop navigation; Friends is also under Profile on mobile. The existing Add menu remains in the bottom bar and is also accessible through More ways to add.

Yardage Book replaces the visible Passport name and provides Places, Highlights and Memories, with all-time/year filtering. Places uses Leaflet/OpenStreetMap with selectable numbered markers, fit-all and course detail/history actions. Directory selections save course coordinates as optional private journal metadata. Existing rounds can be placed explicitly through course search. Unknown locations are never guessed; sample rounds are excluded from the book and focused Home summaries. No database migration is required. Existing V7 backups without location remain valid. Optional locations have coordinate/address validation. Photos remain private unless the existing accepted-friends posting option is selected.

Motion uses short navigation/dialog transitions and map fly-to. Reduced-motion preferences disable these animations. Map library and tiles require connectivity; the course list remains usable if map loading fails. OpenStreetMap attribution remains visible.

Design references: https://flighty.com/ and https://developer.apple.com/news/?id=970ncww4 — a focused current action and a separate personal history with maps and meaningful statistics. This applies that hierarchy to golf rather than copying Flighty's presentation. Mapping implementation: https://leafletjs.com/examples/quick-start/ and https://operations.osmfoundation.org/policies/tiles/ . No bulk tile downloads or offline prefetch.

Verification: build, features, cloud, social and journey checks pass. Local browser review at 320/390px mobile and 1440px desktop checked Home, bottom navigation, real Photon course selection, saving a guest-only QA round, live map tiles, selected-course history and Highlights. No QA round was uploaded to Supabase or posted to friends. Existing account/cloud tests verify isolation and persistence; this release does not change backend policies. Physical device testing remains outstanding.
